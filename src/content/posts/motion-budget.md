炫技和设计的分界线，在于是否可控。一个页面同时飞入十张卡片、粒子在背景里漂浮、鼠标经过就放大三倍——这些效果单独看都成立，放在一起就变成了噪音。

## 动效的三层强度

我给全站动效分了层，每一层的强度上限不同：

| 层级 | 范围 | 强度 |
| --- | --- | --- |
| 品牌层 | 首页首屏、路由切换、404 | 可以强，允许编排 |
| 内容层 | 正文、目录、阅读进度 | 只在必要时出现 |
| 反馈层 | 按钮、复制、悬停 | ≤ 160ms，必须快 |

分层的好处是，当你想在正文里加一个效果时，会先问：它属于哪一层？如果答案是「品牌层」，那它就不该出现在文章页。

## 只动三个属性

性能红线只有一条：只动画 `transform`、`opacity`、`clip-path`。这三个属性都可以交给合成器，不触发布局与重绘。

宽高、`top`、`left`、`margin` 这类属性即使动画曲线再漂亮，也会让每一帧重新计算布局。在低端设备上，这就是掉帧的来源。

```css
/* 对的做法：用 scaleY 代替 height */
.toc-link::before {
  transform: scaleY(0);
  transform-origin: top;
  transition: transform 160ms cubic-bezier(0.25, 1, 0.5, 1);
}

.toc-link.is-active::before {
  transform: scaleY(1);
}
```

## 一套 token 管住节奏

全站的时长和缓动只允许来自这几个变量：

```css
:root {
  --dur-1: 80ms;   /* hover、按下 */
  --dur-2: 120ms;  /* 淡入淡出 */
  --dur-3: 200ms;  /* 路由、抽屉 */
  --dur-4: 320ms;  /* 贴纸、灯箱 */
  --dur-5: 480ms;  /* 首屏开幕 */
  --ease-expo: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

组件里不允许写 `0.3s ease` 这种魔法数字。统一 token 之后，调整节奏只需要改一处，整站的手感会一起变化。

### 主题一致比花样重要

这套视觉语言只允许几类动作：位移、遮罩擦除、扫描线、网点、描边、RGB 错位。弹性缩放、模糊光晕、漂浮粒子一律不用。

限制不是为了保守，而是为了让每一个出现的动作都能被认出「这是这个站点的动效」。当动作有了辨识度，酷才成立。

## 首屏入场的时间表

首屏是唯一允许编排序列的地方。总时长控制在 900ms 以内：

1. 0–80ms：底色到位，内容保持不可见
2. 80–560ms：1px 荧光扫描线自上而下
3. 320–560ms：标题按行揭示，每行间隔 60ms
4. 440–760ms：贴纸从 6° 回正到 3°
5. 560–900ms：索引行依次进入，每行间隔 40ms

超过 900ms，用户会开始怀疑页面是不是卡住了。再漂亮的动画也不值得让读者等。

## 降级与尊重

`prefers-reduced-motion` 不是边缘情况。前庭功能敏感的用户会因位移动画感到不适。我的处理是：开启后关闭所有位移、错位、视差与聚光，只保留 ≤120ms 的透明度变化。

触屏设备关闭聚光与磁吸，因为这两者依赖精确的指针位置。低端设备或开启省流模式时，关闭共享元素过渡与视差。

> 动效的终点不是「看起来很厉害」，而是「用起来没有阻碍」。

## 最后

8KB 的预算很紧，但它逼着我做选择。每一次想加效果，都要先删掉一个。最后留下来的，都是真正服务于信息与节奏的动作。
